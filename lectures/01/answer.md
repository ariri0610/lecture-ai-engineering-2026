## 宿題

- 取り組んだレベル：基礎、実装、発展
- やったこと：LoRAについて次の3つの質問を用意し、`gemini-3.5-flash-lite`、`gemini-3.1-flash-lite`、`gemini-3.8-flash` で回答を比較した。各質問を各モデルで3回実行する計画で試した。temperature は既定値。追加モデルには `gemini-2.5-flash` を試したが、APIから提供終了（404）と返ったため、エラー内で案内された `gemini-3.8-flash` に切り替えた。

	| 質問 | `gemini-3.5-flash-lite` | `gemini-3.1-flash-lite` | `gemini-3.8-flash` |
	|---|---:|---:|---:|
	| LoRAとは何ですか？ | 3/3回成功（出力 519, 540, 631 tokens） | 1/3回成功（734 tokens） | 2/3回成功（728, 715 tokens） |
	| LoRAの仕組みを初心者向けに説明してください。 | 3/3回成功（出力 794, 730, 794 tokens） | 0/3回成功 | 2/3回成功（995, 915 tokens） |
	| LoRAと通常のファインチューニングの違いは何ですか？ | 3/3回成功（出力 910, 706, 879 tokens） | 1/3回成功（865 tokens） | 1/3回成功（990 tokens） |

	`gemini-3.1-flash-lite` と `gemini-3.8-flash` では実行中に503（モデル混雑）が発生し、3回分の回答を揃えられない質問があった。表のトークン数は成功した実行の値。
- 結果：`gemini-3.5-flash-lite` は9回答すべてで、LoRAを「モデル全体ではなく一部のパラメータを調整し、追加学習を効率化する方法」と説明した。`gemini-3.1-flash-lite` と `gemini-3.8-flash` の成功回答も同じ要点を含んでいた。`gemini-3.8-flash` は付箋や辞書などの比喩を交え、説明を細かく展開する傾向が見られ、成功した回答の出力トークン数も715〜995 tokensだった（`gemini-3.5-flash-lite` は質問ごとに519〜910 tokens）。同じ質問・モデルでも構成や表現は変化した。
- 気づき・疑問：今回比較した回答の中心的な説明は共通していたが、503により `gemini-3.1-flash-lite` は2回答、`gemini-3.8-flash` は5回答しか得られず、差を十分に比較できたとは言えない。出力トークン数は説明の詳しさの目安にはなるが、回答の正確さそのものを示すものではない。

- 実装したこと：`app/ask.py` に `--chat` モードを追加した。Google GenAI SDK の chat セッションを1回作成し、同じセッションに続けて質問を送ることで、会話履歴を保つ。`/exit` または `/quit` で終了し、各ターンの入力・出力トークン数も表示する。従来の単発質問モードはそのまま利用できる。
- 実行方法：`uv run python -m app.ask --chat`
- 実施結果：実APIで「私の合言葉は『青い鳥』です。覚えてください。」と伝えた後、「先ほどの合言葉は何ですか？」と質問し、2ターン目に「青い鳥」と回答された。usage は1ターン目が入力15・出力31 tokens、2ターン目が入力55・出力14 tokens。
- 検証：対話履歴を確認する回帰テストを追加し、`uv run pytest -q` を実行して13件すべて成功した。

- 発展でやったこと：APIリクエストの直前から応答を受け取るまでを `perf_counter` で計測し、`[latency] elapsed_seconds=...` として秒単位で表示するようにした。プロセス起動とクライアント生成時間は含めない。`gemini-3.5-flash-lite` と `gemini-3.8-flash` で「LoRAとは何ですか？」「AIE2026の講座の宿題にある『3レベル』とは何ですか？」を各3回ずつ質問した。
